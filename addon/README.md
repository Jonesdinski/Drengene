# Lejrbalet Sync 0.4.0 — udviklingsudgave
Originalt addon. Ingen kode fra FlockSync.
Installér LejrbaletSync i Interface/AddOns. Åbn med /lejrbalet.
Gemmer egne karakterer i LejrbaletDB i SavedVariables/LejrbaletSync.lua.
Indeholder guld i kobber, XP, sidste position, gear og skill ranks.
Kræver fortsat klientintegration, lokaliseringskontrol, in-game API-test og installationspakker. Denne udgave er ikke udgivet som færdig brugerpakke.
