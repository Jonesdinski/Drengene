Lejrbalet Sync 0.4.0 — vores eget addon, guld, XP og position.

Installér det originale Lejrbalet Sync-addon fra addon-v0.4.0. Klienten foretrækker LejrbaletSync.lua og læser fortsat FlockSync.lua, hvis den nye fil ikke findes. Eksisterende forbindelsesnøgler og karaktertilknytninger bevares.

Mørkt/orange design og fælles lejrbålsikon. Guld (inklusive 0), XP, sidste zone/koordinater, gear og professionsniveauer uploades over den eksisterende personlige forbindelse. Intet krav om guild.

Luk-knappen skjuler vinduet; Afslut ved ikonet stopper appen helt. Automatisk opstart og upload kan slås fra separat.

Testudgave uden udgiversignatur. Automatiske parser-, addon- og server-tests; rigtig in-game sync, login-opstart og nøglelagring skal stadig afprøves på brugernes computere.
